# Tooling

Lead provides a set of command-line tools to help you write and manage build configurations, all installed with the `lead-build` crate. This section covers the available tools and their usage.

## Available Tools

- **[pb](cli.md#pb)** - The main build compiler that generates `build.ninja` files from Lead configuration
- **[pbfmt](cli.md#pbfmt)** - Code formatter and linter for Lead files
- **[pbls](cli.md#pbls)** - Language server for IDE integration, used by the [VS Code extension](vscode.md)
