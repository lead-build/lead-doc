# VS Code Extension

The **lead-build** extension for Visual Studio Code provides language support for Lead build configuration files. It uses the language server `pbls`, which is installed together with `pb`; see [Getting Started](../getting-started.md).

## Features

- Syntax highlighting for `.pbb` files
- **Go to Definition** - Navigate to symbol definitions
- **Find References** - Locate all references to a symbol
- **Document Symbols** - Outline view of symbols in the file
- **Code Formatting** - Format `.pbb` files consistently
- **Rename** - Refactor symbol names with prepare support
- **Code Folding** - Fold code regions for better readability
- **Semantic Highlighting** - Intelligent token highlighting (variables, parameters, properties, declarations)

## Installation

The extension is available on the [VS Code Marketplace](https://marketplace.visualstudio.com/search?term=lead-build).

Search for "lead-build" in the VS Code Extensions marketplace or install it directly from the command line:

```
code --install-extension pengi.lead-build
```
